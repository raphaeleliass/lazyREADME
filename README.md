# **📊 Prerequisites and Installation**

### Prerequisites

- Python 3.8 or higher
- A code editor or IDE (e.g., VSCode)

### 1. Clone the repository:

```bash
git clone https://github.com/raphaeleliass/lazyREADME.git
```

### 2. Navigate to the project directory:

```bash
cd lazyREADME
```

### 3. Install dependencies:

```bash
pip install -r requirements.txt
```

<br/>

🎉**Congratulations**, You're all set to start using lazyREADME.

# **🕹️ Usage and Examples**

### 💡 Running the Project

Run the script to start creating your README files:

```bash
python app.py
```

### Examples

Generate a README interactively:

```bash
python app.py
```

Or provide a configuration file:

```bash
python app.py --config config.json
```
